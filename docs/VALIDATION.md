## 실패를 먼저 확인한 회귀 수정

최초 52개 계약 테스트가 구현 전에 실패했고 구현 후 통과했다. 별도 검토에서 JSON 숫자·문자 중복 판별, 동등한 숫자 표기, 전부 결측인 합계, 열/행×열 처리 한도, 공식 남은 시간 명시, 단독 Skill 경로 계산을 테스트로 재현하고 수정했다. 최종 전체 67개가 통과했다.

## 설계상 선택과 한계

- 검사 프로그램은 임의 과제 코드를 실행하지 않는다. 실제 기능 실행·테스트는 Codex가 플랫폼의 승인된 도구로 수행해야 한다.
- `verify`는 파일 형식이 모두 정상이어도 **UNVERIFIED/종료 코드 2**를 반환한다. 성공처럼 보이는 미검증 결과를 막기 위한 의도된 동작이다.
- 파일 8 MiB, 표 100,000행·1,024열·행×열 2,000,000, 탐색 500파일/2,000항목/깊이12. 초과는 부분 성공이 아닌 미검증으로 보고한다.
- 세션 기록은 단일 작업자용이다. 다중 프로세스 동시 갱신, 적대적 경로 교체를 완전히 방어하는 OS 샌드박스는 아니다.
- 생성된 CLI JSON 키는 개발 도구용이다. 사용자 안내는 Skill이 쉬운 한국어로 요약하도록 지시한다.
- 단위 테스트의 문서 검사는 구조/필수 문구 검사다. 실제 모델이 지침을 따르는지를 증명하지 않는다.
