# P08. 계획서·보고서·협업 기록 — 사실 기반 문서화

> **선택형 지침:** 실제 과제 상황에 이 번호가 필요할 때만 읽습니다. 공개 저장소 자료 활용이 허용된 **과제 수행 단계** 전용이며, 해당 단계의 공식 지침이 항상 우선합니다. 개인 PC의 클립보드·외부 메모 전사, 비공개 자료 반출, 자동 제출 및 AI 사용 금지 단계의 활용은 금지합니다. 이 파일을 읽은 사실과 실제 실행·검증은 다릅니다.

## 상세 작업 지시

~~~text
실제 과제에서 요구한 문서와 파일명을 먼저 확인해줘. 요구하지 않은 문서를 무리하게 추가하지 말아줘.
현재 작업에서 실제로 확인한 목표·진행 순서·업무 질문·담당자 답변·중요 판단·검증 결과·한계를 바탕으로 문서를 작성해줘.
실행하지 않은 테스트, 받지 않은 답변, 확인하지 않은 성과를 사실처럼 만들지 말아줘.
공식 과제에서 요구한 문서 또는 실제로 중요한 의사결정 이력이 있을 때만 기록해줘. ai-task-kit의 worklog는 선택 기능이며, 작은 수정마다 호출하지 마. 내부 기록 파일을 과제의 제출 문서로 오인하지 말아줘.
읽기 쉬운 한국어를 사용하고 실제 과제 양식을 우선해줘.
~~~
