# P01. 시작 — 문제를 먼저 이해하고 필수 기능부터

> **선택형 지침:** 실제 과제 상황에 이 번호가 필요할 때만 읽습니다. 공개 저장소 자료 활용이 허용된 **과제 수행 단계** 전용이며, 해당 단계의 공식 지침이 항상 우선합니다. 개인 PC의 클립보드·외부 메모 전사, 비공개 자료 반출, 자동 제출 및 AI 사용 금지 단계의 활용은 금지합니다. 이 파일을 읽은 사실과 실제 실행·검증은 다릅니다.

## 상세 작업 지시

~~~text
현재 응시 환경에서 허용된 Codex만 사용해줘.
먼저 실제 과제 README·지시문·기존 파일을 읽어줘. 이미 읽은 시작 지침·선택표는 다시 읽지 말아줘.
공식 규칙과 실제 과제 지침을 항상 우선하고, 도구 폴더와 과제 폴더를 구분해줘.
요구사항을 [반드시 구현할 기능/필수 산출물·경로] [업무 담당자 확인이 필요한 조건] [선택 기능]으로 분류하고, 실제 지침에 명시된 검증 기준을 5줄 내외의 쉬운 한국어로 정리해줘. 배점·기준은 추측하지 마.
불필요한 계획 문서를 추가하지 말고 가장 중요한 필수 결과를 끝까지 실행하는 최소 경로부터 바로 구현해줘. 가능하면 작은 허용된 입력으로 먼저 실행을 확인해줘. 사소한 개발 선택은 스스로 처리해줘.
다만 계산 기준 변경·입력 제외·원본 덮어쓰기 등 결과에 큰 영향을 주는 선택만 이유와 함께 확인해줘.
검증하지 않은 기능은 완료라고 하지 말고, 최종 제출은 내가 직접 하도록 남겨줘.
~~~
