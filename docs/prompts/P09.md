# P09. 최종 제출 전 — 빠진 파일과 미검증 확인

> **선택형 지침:** 실제 과제 상황에 이 번호가 필요할 때만 읽습니다. 공개 저장소 자료 활용이 허용된 **과제 수행 단계** 전용이며, 해당 단계의 공식 지침이 항상 우선합니다. 개인 PC의 클립보드·외부 메모 전사, 비공개 자료 반출, 자동 제출 및 AI 사용 금지 단계의 활용은 금지합니다. 이 파일을 읽은 사실과 실제 실행·검증은 다릅니다.

## 상세 작업 지시

~~~text
과제 지침의 필수 산출물·정확한 파일명·경로를 다시 읽고 현재 작업 폴더와 비교해줘. 도구 폴더가 제출 대상에 섞여 있는지도 확인해줘.
필요한 경우 ai-task-kit의 verify/preflight로 파일 존재·자료 형식·임시 파일·기록 상태를 한 번 종합 점검해줘. 구조 검사의 UNVERIFIED를 반복 실행 실패로 오해하지 말고 실제 기능 테스트 결과와 분리해줘.
실제 프로그램이 동작하는지 확인한 시험 결과와 아직 미검증인 부분을 구분해줘.
웹 과제라면 지정된 실행 명령·진입 경로·필수 파일과 실제 입력→결과·저장 흐름을 확인해줘. 화면에서 내가 확인할 항목과 미검증인 동작을 짧게 분리해줘. 최종 단계에 디자인 재작업·선택 기능 추가를 시작하지 말고 필수 동작과 화면 사용성 문제만 우선 수정해줘.
에디터 저장됨 표시, 저장 충돌, 실제 제출 대상 파일 목록은 내가 직접 확인할 항목으로 알려줘.
파일을 자동 삭제·외부 업로드·Git Push하지 말고, 최종 제출 버튼은 누르지 말아줘.
~~~
