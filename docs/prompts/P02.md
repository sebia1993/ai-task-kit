# P02. 업무 조건이 모호할 때 — 담당자에게 물을 질문

> **선택형 지침:** 실제 과제 상황에 이 번호가 필요할 때만 읽습니다. 공개 저장소 자료 활용이 허용된 **과제 수행 단계** 전용이며, 해당 단계의 공식 지침이 항상 우선합니다. 개인 PC의 클립보드·외부 메모 전사, 비공개 자료 반출, 자동 제출 및 AI 사용 금지 단계의 활용은 금지합니다. 이 파일을 읽은 사실과 실제 실행·검증은 다릅니다.

## 상세 작업 지시

~~~text
현재 과제에서 해석이 모호하거나 서로 충돌하는 조건을 찾아줘.
먼저 README·기존 메시지·자료에서 근거를 찾아서 [확정된 사실]과 [아직 답이 없는 질문]을 구분해줘.
답이 없어 결과가 달라질 수 있는 질문은 중요도 순으로 최대 3개만 작성해줘.
각 질문에 왜 답이 필요한지 한 문장으로 설명하고, 실제 업무 담당자에게 보내는 행위는 내가 직접 하게 해줘.
답변을 임의로 만들지 말고, 그 조건과 무관한 구현은 계속 진행해줘.
확인해야 하는 조건 이외의 필수 작업은 중단하지 말고 진행해줘. 명확한 답변을 받기 전에는 계산·제외 기준을 임의로 확정하지 마.
~~~
