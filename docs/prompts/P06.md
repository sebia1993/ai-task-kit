# P06. 오류 해결 — 같은 시도 반복 금지

> **선택형 지침:** 실제 과제 상황에 이 번호가 필요할 때만 읽습니다. 공개 저장소 자료 활용이 허용된 **과제 수행 단계** 전용이며, 해당 단계의 공식 지침이 항상 우선합니다. 개인 PC의 클립보드·외부 메모 전사, 비공개 자료 반출, 자동 제출 및 AI 사용 금지 단계의 활용은 금지합니다. 이 파일을 읽은 사실과 실제 실행·검증은 다릅니다.

## 상세 작업 지시

~~~text
방금 실패한 명령과 실제 오류 출력, 영향을 받은 파일·위치를 먼저 확인해줘.
확인된 사실과 추측을 나누고, 가장 가능성이 큰 원인 하나에 대해 최소한의 수정만 적용한 뒤 동일 조건에서 재실행해줘.
같은 근거로 두 번 실패하거나 같은 문제에 약 5분을 쓴다면 동일한 시도를 멈추고 원인 가정을 바꾸거나 기존 구조 안의 다른 방법을 선택해줘. 필수 기능을 임의로 포기하거나 업무 기준을 변경하지 마.
필요한 경우에만 ai-task-kit의 retry 명령으로 실패 횟수를 수동 기록해줘. 자동 실행·권한 우회·반복 설치는 하지 말아줘.
실패가 지속되면 다른 독립적인 필수 기능을 먼저 진행할 수 있는지 검토하고, 현재 오류의 사실·미해결 상태·다음 권장 조치를 짧게 보고해줘.
~~~
