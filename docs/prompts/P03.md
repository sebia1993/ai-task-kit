# P03. 실제 구현 — 기존 구조 유지·최소 변경

> **선택형 지침:** 실제 과제 상황에 이 번호가 필요할 때만 읽습니다. 공개 저장소 자료 활용이 허용된 **과제 수행 단계** 전용이며, 해당 단계의 공식 지침이 항상 우선합니다. 개인 PC의 클립보드·외부 메모 전사, 비공개 자료 반출, 자동 제출 및 AI 사용 금지 단계의 활용은 금지합니다. 이 파일을 읽은 사실과 실제 실행·검증은 다릅니다.

## 상세 작업 지시

~~~text
과제의 기존 기술 스택·파일 구조·실행 명령을 먼저 확인해줘.
필수 요구사항과 산출물의 의존관계를 확인하고, 가장 중요한 기능의 입력→처리→출력 최소 실행 경로부터 구현해줘. 새 프레임워크나 외부 패키지는 실제 필요성이 확인된 경우만 검토해줘.
첫 실행 가능한 경로를 만든 후 허용된 작은 입력이나 기존 예제로 실제 실행을 확인해줘. 이후 필수 기능을 확장하고, 수정한 부분의 관련 테스트를 우선 실행해줘.
원본 입력·공식 테스트를 바꾸어 실패를 숨기지 말고, 중요한 문제부터 끝내줘.
기능마다 장문의 계획·보고서를 만들지 말고 주요 단계·중요 오류·판단 필요 시에만 간결하게 보고하며 개발을 이어가줘. 실제 플랫폼 권한 요청과 중요한 업무 판단은 내가 확인하게 해줘.
~~~
