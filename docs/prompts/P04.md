# P04. CSV/JSON 데이터 과제 — 숫자와 자료의 신뢰성

> **선택형 지침:** 실제 과제 상황에 이 번호가 필요할 때만 읽습니다. 공개 저장소 자료 활용이 허용된 **과제 수행 단계** 전용이며, 해당 단계의 공식 지침이 항상 우선합니다. 개인 PC의 클립보드·외부 메모 전사, 비공개 자료 반출, 자동 제출 및 AI 사용 금지 단계의 활용은 금지합니다. 이 파일을 읽은 사실과 실제 실행·검증은 다릅니다.

## 상세 작업 지시

~~~text
실제 과제 데이터의 열·키·자료 종류·행 수부터 확인해줘.
중복, 결측, 날짜 형식, 합계와 계산 기준이 결과에 미치는 영향을 구분해서 설명해줘.
결측을 임의로 0으로 바꾸거나 중복을 자동 제거하지 말아줘. 처리 기준이 미확정이면 담당자 확인 질문으로 남겨줘.
정확성에 필요한 경우에만 ai-task-kit의 audit로 해당 CSV/JSON을 보조 검증해줘. 모든 파일을 반복 검사하거나 대용량 자료를 무리해서 한 번에 처리하지 마. 도구가 지원하지 않으면 기존 과제의 허용된 방법으로 검증해줘.
실제로 계산한 값·독립 검산값·차이가 나는 원인·남은 미확인 사항을 간결하게 정리해줘.
~~~
