# P05. 웹 서비스 과제 — 기능 우선 화면과 Cofa Browser 확인

> **선택형 지침:** 실제 과제 상황에 이 번호가 필요할 때만 읽습니다. 공개 저장소 자료 활용이 허용된 **과제 수행 단계** 전용이며, 해당 단계의 공식 지침이 항상 우선합니다. 개인 PC의 클립보드·외부 메모 전사, 비공개 자료 반출, 자동 제출 및 AI 사용 금지 단계의 활용은 금지합니다. 이 파일을 읽은 사실과 실제 실행·검증은 다릅니다.

**웹 과제일 때만** [기능 우선 웹 화면 지침](../../.agents/skills/ai-task-kit/references/WEB_FUNCTIONAL_UI.md)을 읽습니다. 같은 세션에서 이미 확인했다면 재사용하고, 다른 과제에서는 이 문서를 추가로 읽지 않습니다.

## 상세 작업 지시

~~~text
실제 과제 README에서 웹페이지가 필수인지 먼저 확인하고, 필요한 화면·입력·버튼·결과를 필수 요구사항에 연결해줘. 모든 과제를 대시보드로 만들지 마.
기존 README·package.json 등에서 기술 스택·실행 명령·포트를 확인하고 기존 CSS와 구성요소를 재사용해줘.
가장 중요한 입력→처리→결과 흐름 하나를 먼저 실제로 작동시킨 뒤 필수 기능을 확장해줘. 보기만 하는 버튼이나 예시 숫자로 기능 완료를 보고하지 마.
디자인은 읽기 쉬운 글자, 통일된 버튼과 간격, 필요한 표·입력창 배치까지만 기본 적용해줘. 꾸미기용 패키지·외부 폰트·애니메이션은 추가하지 말고 과제에서 지정한 디자인은 따르도록 해줘.
해당 기능에 필요한 입력 전·처리 중·빈 결과·입력 오류 상태를 안내하고, 화면 잘림과 주요 조작 불가는 기능 문제로 수정해줘.
허용된 환경에서 서버를 실행하고 Cofa Browser의 실제 포트·경로를 확인해줘. 필요한 경우 지침에 맞게 0.0.0.0 바인딩을 사용하되 외부 터널·접속 제한 우회는 하지 마.
화면의 버튼·입력·결과·저장 동작은 내가 내부 Browser에서 확인할 항목으로 알려줘. 직접 확인하지 못한 화면 동작은 미검증으로 표시하고, 연결 문제는 서버 오류→포트→바인딩→경로 순서로 조사해줘.
~~~
