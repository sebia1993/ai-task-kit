# P12. 외부 도구·저장소 사용이 막힐 때 — 우회 없이 계속

> **선택형 지침:** 실제 과제 상황에 이 번호가 필요할 때만 읽습니다. 공개 저장소 자료 활용이 허용된 **과제 수행 단계** 전용이며, 해당 단계의 공식 지침이 항상 우선합니다. 개인 PC의 클립보드·외부 메모 전사, 비공개 자료 반출, 자동 제출 및 AI 사용 금지 단계의 활용은 금지합니다. 이 파일을 읽은 사실과 실제 실행·검증은 다릅니다.

## 상세 작업 지시

~~~text
공개 저장소 가져오기, Skill 읽기, 패키지 설치 또는 명령 실행이 허용되지 않으면 원인을 한 번 확인하고 우회하지 말아줘.
도구 설치를 반복하거나 별도 AI·API·원격 서버에 연결하지 말고, 현재 제공된 Codex와 허용된 기본 환경으로 과제를 수행해줘.
과제 지침부터 확인해 필수 기능을 구현하고, 실행할 수 있는 검증만 실제 수행해줘.
접속·감독·플랫폼 장애라면 Cofa 내 문제 신고를 이용하도록 알려줘.
~~~
